# Financial KPI Dashboard Standard

The executive financial dashboard must present a controlled set of decision-useful indicators, including cash position, runway, receivables aging, revenue, contribution margin, operating expense, budget variance, recurring commitments, debt and credit utilization, and forecast confidence.

Every KPI requires a definition, owner, source, refresh cadence, target or threshold, and escalation rule. Dashboard values must link to supporting evidence and clearly label estimates, incomplete data, and stale information.
