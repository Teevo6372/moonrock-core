# Moonrock Enterprise Foundation

**Program:** 002 — MBOS Alpha Implementation  
**Sprint:** 001 — Build the Foundation  
**Lifecycle Status:** Implemented  
**Version:** 0.1.0

This directory is the governed enterprise layer for Moonrock Business Operating System (MBOS).

## Scope

- Enterprise governance
- MBOS standards
- Architecture and capability management
- Program and release controls
- Repository intelligence

## Operating Principles

1. Protect existing production assets.
2. Build additively before migrating.
3. Document before changing.
4. Validate before releasing.
5. Preserve traceability through Git history.
