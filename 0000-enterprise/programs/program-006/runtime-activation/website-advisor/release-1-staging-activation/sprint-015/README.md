# Sprint 015 — Controlled Private Staging Deployment

This folder contains the operator-controlled activation package for Nova Release 1 private staging.

- `PRIVATE-STAGING-ACTIVATION-RUNBOOK.md` — provisioning, validation, restart, rollback, and stop conditions.
- `OPERATOR-ACCEPTANCE-RECORD.md` — sanitized deployment identity, evidence references, and acceptance decision.
- `IMPLEMENTATION-RECORD.md` — implemented controls, limitations, validation, and completion gate.

No document in this folder authorizes public access, live providers, external writes, production credentials, customer traffic, or production activation.
