# Nova Website Advisor Release 1 Staging Activation — Sprint 007

## Objective

Define the smallest safe limited-pilot envelope and the evidence required for
a later human production decision. Convert operating hours, owners, data,
support, traffic, cost, CRM, success, stop, WordPress, and rollback
requirements into executable gates.

## Planning-only boundary

This sprint does not:

- approve or launch a pilot;
- assign a person merely by naming a placeholder role;
- connect providers or add credentials;
- deploy the runtime or alter infrastructure;
- modify GHL, WordPress, XStore, Elementor, DNS, or production;
- embed the Nova client;
- approve production.

## Deliverables

- candidate pilot plan;
- named-owner and approval matrix;
- Central Time operating-window and support contract;
- data/retention boundary;
- traffic, message, model-token, cost, and GHL-write ceilings;
- runtime admission and kill-switch gate;
- support and human-handoff targets;
- success and immediate-stop criteria;
- production architecture and WordPress integration/rollback plan;
- pilot evidence and executive go/no-go decision gate.

## Exit gate

All planning artifacts and executable controls must be reviewable and
reversible. Owner merge approval authorizes only the plan; pilot launch and
production remain separate decisions.
