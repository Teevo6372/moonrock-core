# Moonrock Enterprise Glossary

**Document ID:** MBOS-STD-GLS-001  
**Program:** 002 — MBOS Alpha Implementation  
**Sprint:** 001  
**Version:** 0.1.0  
**Lifecycle Status:** Implemented

| Term | Definition |
|---|---|
| MBOS | Moonrock Business Operating System. |
| Capability | A reusable business or technical function that delivers measurable value. |
| Program | A governed collection of related work packages and missions. |
| Sprint | A time-boxed implementation increment producing reviewable deliverables. |
| Mission | A discrete implementation objective within a program or sprint. |
| Work Package | A grouped set of deliverables with a shared objective. |
| Division | A Moonrock business unit operating under enterprise governance. |
| Product | A maintained capability or platform with an owner, roadmap, lifecycle, and releases. |
| ADR | Architecture Decision Record. |
| Client Workspace | A standardized, governed structure used to deliver services for a client. |
| RDR | Repository Disposition Register. |
| RDM | Repository Dependency Map. |
| ACR | Asset Classification Register. |
| Lifecycle Status | The current governed state of an artifact: Draft, In Review, Approved, Implemented, Operational, Superseded, or Archived. |
| Protected Asset | A production asset that cannot be moved, deleted, or materially changed without dependency review, rollback planning, approval, and release documentation. |
