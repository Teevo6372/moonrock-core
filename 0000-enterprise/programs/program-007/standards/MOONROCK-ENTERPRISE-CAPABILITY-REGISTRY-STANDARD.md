# Moonrock Enterprise Capability Registry Standard

The MECR is the governed index of enterprise capabilities. It is not a live workflow engine.

## Required Fields
Capability ID, name, division, objective, owner, lifecycle status, maturity level, inputs, outputs, knowledge sources, runtime systems, dependencies, approval gates, Nova role, automation readiness, metrics, risks, revenue path, priority, evidence, and last review.

## Lifecycle
Identified → Specified → Approved → Implementation Ready → Pilot → Production → Validated → Optimized → Retired.

## Maturity
0 Unrecognized; 1 Identified; 2 Documented; 3 Controlled; 4 Operational; 5 Measured; 6 Optimized.

## Governance
Status changes require evidence and the authority defined by MBOS. Documentation alone cannot advance a capability to Pilot, Production, Validated, or Optimized. Conflicts are escalated to the capability owner and governing authority.
