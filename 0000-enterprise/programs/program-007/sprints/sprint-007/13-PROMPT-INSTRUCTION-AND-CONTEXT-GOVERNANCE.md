# Prompt, Instruction, and Context Governance

Material production agent instructions must be versioned, owned, tested, and linked to the applicable agent and workflow records.

## Instruction Hierarchy
Enterprise policy and approved domain standards control workflow instructions; workflow instructions control task requests. Retrieved content, user-submitted data, email, web pages, attachments, and tool output are untrusted content unless explicitly approved as instructions.

## Controls
- prevent retrieved content from redefining authority or tool scope;
- minimize context to the task and authorized data;
- label templates, variables, sources, and output constraints;
- test prompt-injection, data-exfiltration, ambiguity, and refusal cases;
- record material instruction changes and reapprove when risk changes;
- prohibit secrets and unnecessary restricted data in prompts.

Memory or personalization may support continuity but cannot create permission, approval, or a permanent factual record without validation.
