**Program:** 002 — MBOS Alpha Implementation  
**Sprint:** 001

## Baseline Position

The initial baseline is qualitative until automated checks and a complete file-level inventory are implemented. No unsupported numerical score is assigned in Sprint 001.

| Category | Initial State | Evidence Needed for Scoring |
|---|---|---|
| Governance | Established | Required governance files, ownership, approval records |
| Documentation coverage | Partially measured | Complete inventory and mapped documentation requirements |
| Version control | Established | Repository-wide asset verification |
| Product separation | In progress | Product boundary and dependency audit |
| Architecture traceability | Established in part | ADR coverage analysis |
| Automation | Established in part | Workflow inventory and test results |
| Metadata compliance | Not yet measured | Automated metadata validator |
| Broken references | Not yet measured | Automated internal-link checker |
| Duplicate content | Not yet measured | Repository content analysis |
| Orphaned assets | Not yet measured | File ownership and dependency inventory |

## Target Measures

- Documentation coverage: 100% for governed assets
- Version-controlled governed assets: 100%
- Required metadata compliance: 100%
- Broken internal references: 0
- Duplicate document IDs: 0
- Unassigned protected assets: 0
- Architectural decisions with ADR coverage: 100%

## Scoring Gate

A numerical repository health score may be published only after the measurement method, evidence sources, and weighting model are committed and reviewed.
