# MBOS Alpha Release Notes

**Document ID:** MRE-P002-REL-001  
**Version:** 0.1.0  
**Status:** In Review  
**Owner:** Moonrock Enterprises

**Effective date:** 2026-07-28

## Release summary

MBOS Alpha establishes the first governed operating-system baseline for Moonrock Enterprises inside `moonrock-core`.

## Included

- Enterprise repository structure and navigation
- Repository disposition and asset classification controls
- Dependency, glossary, technical debt, and repository health records
- Documentation, numbering, lifecycle, versioning, and client-identification standards
- Program management and architecture review governance
- Decision, exception, quality-gate, and capability management controls
- Executive dashboard specification
- AI and repository automation standards
- Metadata validation and release automation specifications
- Program release-readiness and completion evidence

## Not included

- Production workflow deployment
- Credentials or live service integrations
- Client workspace generation
- Mentorship Phase 3 implementation
- Program 003 enterprise intelligence implementation
- Existing production asset migration

## Compatibility and risk

This release is documentation-first and additive. It does not intentionally change runtime behavior, deployed websites, commerce applications, or production integrations.

## Next controlled decision

After approval and baseline freeze, the next program must be selected through the Program Management Framework and governed by the Enterprise Architecture Review Board where applicable.
