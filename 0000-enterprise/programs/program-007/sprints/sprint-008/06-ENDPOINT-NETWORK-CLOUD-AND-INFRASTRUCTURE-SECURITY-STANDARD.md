# Endpoint, Network, Cloud, and Infrastructure Security Standard

Technology environments must use secure configuration baselines, supported software, controlled administration, network segmentation proportionate to risk, protected remote access, monitoring, backup, and documented ownership.

## Minimum Controls
- authorized inventory and hardened defaults;
- timely security updates and supported lifecycle;
- endpoint protection and screen or session locking;
- firewalls, secure wireless, and restricted management interfaces;
- encrypted administrative access;
- separation of production, test, guest, client, and management contexts where applicable;
- configuration backup and controlled change;
- detection and alerting for material security events.

Public exposure requires explicit review. Default credentials, unnecessary services, and unsupported production systems are prohibited without approved exception and compensating controls.
