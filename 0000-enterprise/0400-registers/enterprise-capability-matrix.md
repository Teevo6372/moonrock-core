## Purpose

Evaluate each governed capability across ownership, process, documentation, technology, control, and measurement dimensions.

| Level | Meaning |
|---|---|
| 0 | Not defined |
| 1 | Drafted |
| 2 | Implemented |
| 3 | Operational |
| 4 | Measured |
| 5 | Optimized |

## Review rules

- Scores require supporting evidence.
- Overall maturity is the rounded-down average of the six dimensions.
- A capability cannot be rated Operational when ownership, process, or controls are below level 3.
- Material score changes require a dated review entry.
- Unsupported estimates must be labeled provisional.

## Review cadence

Review the matrix at each program release and whenever a capability changes lifecycle state.
