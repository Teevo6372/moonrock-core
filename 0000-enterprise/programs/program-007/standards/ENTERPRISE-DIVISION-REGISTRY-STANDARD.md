# Enterprise Division Registry Standard

Each Moonrock division record must include:

- Division ID and approved name
- Mission and scope
- Executive owner and operational owner
- Operating status
- Services and products
- Capability IDs
- Revenue model
- Primary runtime systems
- Key dependencies
- Approval authorities
- Nova responsibilities and boundaries
- KPIs and reporting cadence
- Material risks and compliance considerations

## Registered Divisions

1. Moonrock Mentorship
2. Moonrock Marketing
3. Moonrock MTG Pro Seller
4. Moonrock Systems
5. Moonrock Marketplace
6. Moonrock Properties

A division is not considered active merely because it is documented. Activation requires ownership, minimum capabilities, approved runtime systems, defined controls, measurable outcomes, and executive authorization.
