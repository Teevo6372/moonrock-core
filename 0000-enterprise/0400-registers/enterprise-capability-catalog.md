## Purpose

Provide the authoritative inventory of governed Moonrock enterprise capabilities.

## Required capability record

Each capability record must include:

- Capability ID
- Name and purpose
- Business owner
- Technical or operational owner
- Lifecycle state
- Version
- Dependencies
- Acceptance criteria
- Test or validation method
- Release notes reference
- Roadmap state
- Known risks or debt
