# Moonrock Marketing Small Business Mentorship Platform - Client Onboarding & Operating Agreement

**Document ID:** MMC-LGL-1001  
**Version:** 1.0.0  
**Owner:** Moonrock Marketing Corp.  
**Repository:** moonrock-core

## Purpose
This package establishes the reusable onboarding, authorization, mentorship, Acting COO, payment, banking-assistance, access, ownership, termination, and graduation framework for Moonrock Marketing Corp. mentorship clients.

## Files
- Fillable PDF: production client packet with interactive text fields.
- DOCX: editable source master.
- `agreement-source.md`: repository-native source text.
- `CHANGELOG.md`: revision history.
- `VERSION.md`: document-control record.

## Workflow
1. Moonrock completes all fields marked **MOONROCK INTERNAL**.
2. Export or distribute a client-specific copy.
3. Client completes intake, authorizations, initials, and signatures.
4. Moonrock countersigns and stores the executed copy outside the public repository.
5. Never commit client PII, banking credentials, signatures, or executed agreements to a public repository.

## Internal Fields
PDF form technology does not reliably restrict an individual field to one named person across all PDF viewers. Moonrock-only fields are clearly marked and must be controlled through distribution workflow, permissions, and retention procedures.

## Legal Review
This operational template should be reviewed by a Kansas-licensed attorney before production use, especially banking, agency, ACH, intellectual-property retention, suspension, mediation, and arbitration provisions.
